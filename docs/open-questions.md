# open-questions（未決事項）

本書は「決めないと実装が進められない」未決を集約します。
回答が得られるまで、実装側は推測で埋めないでください。

## 確定事項（参照用）

| 項目 | 内容 |
|------|------|
| 4面同期の範囲 | `TOP` → `ANIMATION` → `PRODUCT_LIST` まで |
| PRODUCT_LIST 以降 | 各モニター操作は独立 |
| CATEGORY | 独立 screenState ではなく `PRODUCT_LIST` 上の `categoryDrawer`（UX名称として CATEGORY は可） |
| IMAGE_ZOOM | overlay UI（`PRODUCT_DETAIL` 上）。`screenState` は独立可。×は常に `PRODUCT_LIST` |
| PRODUCT_DETAIL の × | `PRODUCT_LIST` へ戻る |
| FESTIVAL | 廃止（function.xlsx から削除） |
