# 画面遷移図
## B案：探索デザイン重視型

## 概要
スリープ画面（4面表示）から探索体験へ誘導し、
探索（カテゴリ・詳細・画像拡大）を回遊する構成。
特殊導線として、指定箇所のダブルタップで「祝祭演出（3〜5秒）」を挟んで探索へ遷移する。

## Mermaid

```mermaid
flowchart TD
  TOP1[トップ-1(スリープ)]
  TOP2[トップ-2(スリープ)]
  TOP3[トップ-3(スリープ)]
  TOP4[トップ-4(スリープ)]

  FEST[祝祭演出(3-5秒)]
  ANIM1[アニメーション_1]
  EXP[探索画面]
  CAT[カテゴリ画面]
  DET[詳細画面]
  ZOOM[画像拡大(モーダル)]

  TOP1 -->|指定箇所タップ| ANIM1
  TOP1 -->|指定箇所ダブルタップ| FEST
  FEST --> ANIM1
  ANIM1 --> EXP

  TOP2 --> ANIM1
  TOP3 --> ANIM1
  TOP4 --> ANIM1

  EXP -->|画像タップ| ZOOM
  ZOOM -->|×| EXP

  EXP -->|ハンバーガーメニュー| CAT
  CAT -->|×| EXP
  CAT -->|カテゴリ選択| DET
  DET -->|×| CAT

  EXP -->|一定時間操作なし| TOP1
  CAT -->|一定時間操作なし| TOP1
  DET -->|一定時間操作なし| TOP1
  ZOOM -->|一定時間操作なし| TOP1
```

## 画面定義

| ID | 画面名 | 役割 |
|---|---|---|
| TOP_1 | トップ-1 | スリープ画面（4面表示）の一種。探索体験への入口 |
| TOP_2 | トップ-2 | スリープ画面（4面表示）の一種。探索体験への入口 |
| TOP_3 | トップ-3 | スリープ画面（4面表示）の一種。探索体験への入口 |
| TOP_4 | トップ-4 | スリープ画面（4面表示）の一種。探索体験への入口 |
| FESTIVAL | 祝祭演出 | 特別アニメーション（3〜5秒）。探索体験へ誘導 |
| ANIMATION_1 | アニメーション_1 | 探索画面遷移前アニメーション |
| EXPLORE | 探索画面 | 40〜70枚画像の探索。ピンチ/スワイプ/タップ/メニュー |
| CATEGORY | カテゴリ画面 | カテゴリ一覧・選択・×で探索へ復帰 |
| DETAIL | 詳細画面 | 縦スクロール（4セクション程度）＋左右スワイプで次画像。×でカテゴリへ |
| IMAGE_ZOOM | 画像拡大画面 | フルスクリーン画像表示（モーダル）。×で探索へ |

## 遷移ルール

- トップ（スリープ）から、指定箇所タップで `ANIMATION_1` へ遷移する
- トップ（スリープ）から、指定箇所ダブルタップで `FESTIVAL` を再生後 `ANIMATION_1` へ遷移する
- `ANIMATION_1` 終了で `EXPLORE` へ遷移する
- `EXPLORE` の画像タップで `IMAGE_ZOOM`（モーダル）を開き、×で `EXPLORE` に戻る
- `EXPLORE` からハンバーガーメニュー操作で `CATEGORY` を開き、×で `EXPLORE` に戻る
- `CATEGORY` でカテゴリ選択すると `DETAIL` に遷移し、×で `CATEGORY` に戻る
- `EXPLORE/CATEGORY/DETAIL/IMAGE_ZOOM` は一定時間操作なしで `TOP_1` へ復帰する（スリープ）

## 実装メモ

この画面遷移をもとに、React/Unity/TouchDesigner等で画面状態管理を実装する。
各screen.idを状態名として扱う。
