- [ ] スリープ無効

## 自動更新/再起動

- [ ] 展示中に勝手に再起動しない運用（Windows Update）
- [ ] Chrome の自動更新方針（固定 or 管理）

## 自動起動/復帰

- [ ] 電源投入→ログイン→Chrome起動→全画面表示まで自動復帰できる
- [ ] クラッシュ時の復帰手順（手動/自動）
