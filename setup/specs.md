# 推奨スペックと前提（展示 / 開発）

## 展示PC（新規調達）推奨

- **解像度**: フルHD（1920x1080）
- **入力**: マルチタッチ（Windows）
- **CPU**: Core i5 / Ryzen 5 以上（世代新しめ推奨）
- **メモリ**: 32GB 推奨（最低 16GB）
- **GPU**: dGPU 推奨（例: RTX 3060 / 4060 クラス）
- **ストレージ**: SSD 1TB 推奨（最低 512GB）

## 開発PC（外注 / Web担当）

- **メモリ**: 16GB 以上（32GB が快適）
- **GPU**: L1開発のみなら不要（展示PCでの実機確認は別途）

## ブラウザ

- **本番ブラウザ**: Chrome（固定運用を推奨）
- 展示中の自動更新はリスクがあるため、運用方針を `kiosk/windows-settings-checklist.md` にまとめる
