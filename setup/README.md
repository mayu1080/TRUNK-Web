# 環境構築（Setup）

このフォルダは、展示PC・開発PC向けの **環境構築手順** と、運用で使う **設定スクリプト（.ps1 / .bat）** をまとめる場所です。

## 目的

- 展示端末（55inch / FHD / マルチタッチ）で、安定して動作する実行環境を再現できること
- 外注/社内の開発端末で、同じ手順で起動・確認できること

## フォルダ構成

- `kiosk/`: 展示PC向け（Chrome kiosk起動、Windows設定チェック等）
- `dev/`: 開発PC向け（セットアップ、起動手順）
- `content/`: コンテンツ差し替え（manifest仕様、将来の遠隔更新方針）
- `ops/`: 受け入れ基準、トラブルシュート

## 実行について

このフォルダに置くスクリプトは、PC設定や起動動作に影響します。
**実行前に内容を必ず確認**し、必要なら展示PC用に調整してください。
