# インストール（モジュールと手順）

production を動かすには **install が 2 回**必要。リポジトリ直下には `package.json` が無い。`app` だけ入れても画面（React / Three）は入らない。

---

## 使うモジュール

手で一つずつ `npm install three` する必要はない。各フォルダで `npm ci` すれば下表が入る。

### 1. `app/`（Electron 本体）

`app/package.json` の内容。

| モジュール | 用途 |
|------------|------|
| `electron` | 4 画面ウィンドウを出すシェル |
| `typescript` | Main プロセス（`app/electron`）のビルド |
| `@types/node` | Node / Electron 用の型 |

ここには **`three` も `react` も無い**。それが正常。

### 2. `app/renderer/production/`（本番画面）

`app/renderer/production/package.json` の内容。

| モジュール | 用途 |
|------------|------|
| `react` / `react-dom` | UI |
| `three` | PRODUCT_LIST の 3D |
| `@types/react` / `@types/react-dom` | TS7026 対策に必須 |
| `@types/three` | Three の型。不足すると型エラーで **起動できない** |
| `vite` / `@vitejs/plugin-react` | 画面のビルド |
| `typescript` | `start:production` 前の型チェック |

### 入れないもの（現場 production）

| フォルダ | 理由 |
|----------|------|
| `app/renderer/demo-0820` | 8/20 デモ。本番起動に不要 |
| `app/renderer/demo-0820-color` | 同上 |
| `LIST_demo` | このブランチには含まれない |

## 手順の流れ

コマンドは PowerShell 想定。`cd` したあと、そのフォルダで `npm ci`。

1. **Node を確認する**  
   `node -v` が **v22.12.0 以上**。古いと `electron@43` の install が落ちる。

2. **リポジトリをクローンする**  
   手順は [README.md](./README.md)。

3. **USB の `content/` を載せる**  
   Git には画像・mp4・フォント・Logo・text は入っていない。クローン直後のままでは LIST / ANIMATION が空になる。

4. **`app` でモジュールを入れる**  
   リポジトリ直下ではなく **`app` フォルダ**。  
   `npm ci`（lock どおり。推奨）または `npm install`。  
   成功すると `app/node_modules/electron` ができる。初回は Electron 本体のダウンロードで数分かかることがある。

5. **`app/renderer/production` でモジュールを入れる**  
   ここを忘れると TS7026・Three 不足が出る。  
   同じく `npm ci`。  
   成功すると `node_modules/three` と `node_modules/@types/react` ができる。

6. **入ったか確認する**（起動前）

   - `app/node_modules/electron` がある
   - `app/renderer/production/node_modules/three` がある
   - `app/renderer/production/node_modules/@types/react` がある
   - `app/renderer/production/node_modules/@types/three` がある

   足りなければ、足りない側のフォルダで `npm ci` をやり直す。`npm run dev` はしない。

7. **起動する**  
   [起動コマンド.md](./起動コマンド.md)。作業ディレクトリは常に **`app`**。

---

## コマンド例（コピー用）

クローン後、リポジトリの中で:

```powershell
cd app
npm ci
cd renderer\production
npm ci
cd ..\..
```

最後の `cd ..\..` で `app` に戻る。この状態で起動コマンドを打つ。

`npm ci` がネットワークで失敗したら、同じフォルダでもう一度。個別パッケージを足すより、失敗した階層の `npm ci` を完了させる。

## よくある誤解

| やったこと | 結果 |
|------------|------|
| リポジトリ直下で `npm install` | 入れる先が無く、何も揃わない |
| `app` だけ `npm ci` | Electron は入る。画面の Three / React 型は入らない |
| エラーが出たので `npm run dev` | モジュールは増えない。別の起動になる |
| `demo-0820` に `npm ci` | 本番 renderer とは別物 |
